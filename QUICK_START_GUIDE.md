## 📸 Uploading Your Profile Photo

### Method 1: From Dashboard Header (Recommended)

1. **Login to your dashboard**
   - Admin: Click "Admin" → Login
   - Teacher: Click "Teacher" → Login  
   - Student: Click "Student" → Login

2. **Look for your profile picture** in the top-right corner
   - It shows your initials or current photo

3. **Click on your profile picture**
   - A dropdown menu appears

4. **Select "Upload Photo"**
   - A file browser opens

5. **Choose your image**
   - Supported formats: JPG, PNG, GIF, WebP
   - Max file size: 5MB

6. **Photo uploads automatically** ✅
   - See it update in your profile
   - Appears across all panels

### Method 2: From Navbar

1. Click your profile picture in the main navigation bar
2. Select "Upload Photo" from dropdown
3. Choose and upload your image

## ✅ Approving/Rejecting Applications (Admin)

### Step-by-step

1. **Go to Admin Dashboard**
   - URL: `/dashboard/admin`
   - Or click "Admin Portal" from Dashboard menu

2. **Click "Applications"** in the menu
   - Shows application review queue

3. **Filter by status**
   - Click "Pending" to see new applications
   - Click "Approved" to see approved ones
   - Click "Rejected" to see rejected ones

4. **Click an application** to view details
   - See applicant's photo
   - View all application information

5. **Add remarks** (optional)
   - Type feedback in the remarks field

6. **Click "Approve"** or **"Reject"**
   - Shows "Processing..." while updating
   - Success/error message displays
   - Application removed from pending list

## ❓ Frequently Asked Questions

**Q: My photo isn't showing up?**
A: 
- Clear your browser cache (Ctrl+F5)
- Try uploading again
- Check file format (JPG, PNG, GIF, WebP)
- Verify file size < 5MB

**Q: How do I change my password?**
A: 
- Go to your profile settings in dashboard
- Look for "Settings" option (coming soon)

**Q: Can I delete my photo?**
A:
- Upload a new one to replace it
- Or contact admin for removal

**Q: Why is approval/rejection slow?**
A:
- Normal processing takes 1-2 seconds
- Your connection speed matters
- Server load might cause delays

**Q: What if logout doesn't work?**
A:
- Hard refresh page (Ctrl+F5)
- Clear browser cookies
- Try again

## 🆘 Troubleshooting

### Photo Upload Fails
1. Check file format (must be image)
2. Verify file size < 5MB
3. Ensure you're logged in
4. Try a different browser
5. Refresh page and try again

### Can't Find Applications
1. Make sure you're logged in as admin
2. Click "Applications" in menu
3. Check filter (Pending, Approved, Rejected)

### Logout Not Working
1. Hard refresh (Ctrl+F5 / Cmd+Shift+R)
2. Clear browser cache
3. Try logout again
4. Check browser console for errors

### Dashboard Not Loading
1. Refresh page
2. Clear browser cache
3. Check internet connection
4. Try different browser
