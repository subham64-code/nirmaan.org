# Nirmaan Backend

Production-ready Express + MongoDB API for the nirmaan.org education platform.

## Features
- Role-based auth (Admin, Teacher, Student)
- OTP login for Admin and Teacher
- Student application approval workflow
- Attendance tracking
- Test creation and submission with scoring
- Performance management
- Media upload and listing
- Admin analytics and action logs

## Setup
1. Copy `.env.example` to `.env`
2. Install dependencies: `npm install`
3. Start development server: `npm run dev`

## Scripts
- `npm run dev` - Run with nodemon
- `npm start` - Run production server

## API Base
- `http://localhost:5000/api`
