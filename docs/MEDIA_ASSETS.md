## Image Specifications

### Recommended Image Sizes

- **Trainer Photos**: 400x400px (square), high resolution (minimum 1200x1200px)
- **Course Banners**: 1920x1080px (16:9 aspect ratio)
- **Gallery Images**: 1920x1080px (16:9) or 1200x800px (3:2)
- **Logos**: 
  - Horizontal: 300x100px
  - Square: 200x200px
  - SVG format preferred for scalability

### Image Formats

- **Photos**: JPG (high quality, 80-90% compression)
- **Graphics/Logos**: PNG (with transparency) or SVG
- **WebP**: Modern format, smaller file size, good for web

### File Size Guidelines

- **Trainer Photos**: < 500KB
- **Course Banners**: < 1MB
- **Gallery Images**: < 500KB each
- **Logos**: < 100KB

## Video Specifications

### Recommended Video Settings

- **Resolution**: 1920x1080 (Full HD) or 1280x720 (HD)
- **Format**: MP4 (H.264 codec)
- **Frame Rate**: 30 fps
- **Bitrate**: 5-10 Mbps for HD, 2-5 Mbps for lower quality
- **Audio**: AAC, 128-192 kbps, 44.1 kHz

### Video Duration Guidelines

- **Trainer Intros**: 1-2 minutes
- **Course Overviews**: 2-3 minutes
- **Facility Tours**: 3-5 minutes
- **Testimonials**: 30 seconds - 1 minute
- **Event Videos**: 5-10 minutes (highlights)

### File Size Guidelines

- **Short Videos (< 2 minutes)**: < 50MB
- **Medium Videos (2-5 minutes)**: < 100MB
- **Long Videos (5-10 minutes)**: < 200MB

## How to Add New Assets

### Adding Photos

1. **Place image in appropriate folder** in `public/`
2. **Update constants.ts** if the image is referenced there
3. **Update component** that uses the image
4. **Test** that the image displays correctly

Example:
```typescript
// In constants.ts
export const courses = [
  {
    title: "AI/ML",
    bannerImage: "/images/courses/course-ai-ml-banner.jpg",
    // ...
  }
];
```

### Adding Videos

1. **Place video in appropriate folder** in `public/videos/`
2. **Update constants.ts** with video path
3. **Update component** to use local video instead of YouTube embed
4. **Test** that video plays correctly

Example:
```typescript
// In constants.ts
export const trainerProfiles = [
  {
    name: "Krishan Kumar",
    video: "/videos/trainers/trainer-krishan-intro.mp4",
    // ...
  }
];
```

### Using Local Videos in Components

For HTML5 video playback:
```tsx
<video controls width="100%">
  <source src="/videos/trainers/trainer-krishan-intro.mp4" type="video/mp4" />
  Your browser does not support the video tag.
</video>
```

For background video:
```tsx
<video autoPlay muted loop playsInline className="absolute inset-0 w-full h-full object-cover">
  <source src="/attendance-media/about-us-background.mp4" type="video/mp4" />
</video>
```

## Asset Optimization

### Image Optimization

1. **Use appropriate formats**: WebP for modern browsers, fallback to JPEG/PNG
2. **Compress images**: Use tools like TinyPNG, ImageOptim, or Squoosh
3. **Use Next.js Image component**: For automatic optimization
```tsx
import Image from 'next/image';

<Image 
  src="/trainer-kalpa.jpg" 
  alt="Kalpa Pandit" 
  width={400} 
  height={400} 
/>
```

### Video Optimization

1. **Use appropriate compression**: HandBrake, FFmpeg
2. **Create multiple quality versions**: 1080p, 720p, 480p
3. **Use streaming**: HLS/DASH for long videos
4. **Lazy load videos**: Load only when needed

## Asset Management Best Practices

1. **Version Control**: Keep assets in Git if small, use external storage for large files
2. **Naming Convention**: Use descriptive, lowercase names with hyphens (e.g., `trainer-kalpa.jpg`)
3. **Alt Text**: Always provide descriptive alt text for accessibility
4. **Responsive Images**: Provide multiple sizes for different screen sizes
5. **Lazy Loading**: Load images/videos only when needed for better performance
6. **CDN**: Use CDN for production to serve assets faster
7. **Backup**: Keep backup of all original high-quality assets
8. **Documentation**: Document source and usage rights for all assets
